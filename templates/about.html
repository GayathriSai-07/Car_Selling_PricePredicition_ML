🚗 About CarPrice AI

Smart Car Price Prediction

CarPrice AI is a machine learning based web application designed to estimate the approximate selling price of used cars.

🤖

Machine Learning

Our system uses a trained machine learning model to analyze vehicle information and estimate an appropriate selling price.

📊

Data Driven

The model considers important factors such as present price, kilometers driven, car age, fuel type, seller type, transmission and owners.

⚙️

Easy to Use

Users only need to enter their vehicle details and click the prediction button to receive an estimated selling price.

🎯

Project Goal

The goal is to demonstrate how machine learning can be applied to real-world vehicle price prediction and analysis.

Technologies Used

🐍 Python 🌐 Flask 📊 Pandas 🔢 NumPy 🤖 Scikit-learn 🎨 HTML & CSS
